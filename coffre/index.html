Comment utiliser le solveur
  1. Vérifie les énergies du jeu : active celles que ton coffre propose (par défaut les six vues dans le jeu).
  2. Joue l'essai conseillé dans le jeu, touche « J'ai joué ce coup », puis saisis ce que le coffre répond : bien placées (vert) et ailleurs (orange). Valide.
  3. Le solveur garde tous les codes compatibles et conseille l'essai qui en élimine le plus, quel que soit le retour. Le carnet résume ce qui est certain.
  4. Touche un essai passé pour le corriger ou le supprimer.
  5. Clavier : 1…9 ajoutent une énergie (dans l'ordre de la palette), ⌫ retire la dernière, Entrée valide ; en pas à pas, ← →.
