Comment utiliser le solveur
  1. Recopie les compteurs du jeu : pour chaque ligne puis chaque colonne, ses points et son nombre de Voltorbe. Le pavé passe tout seul au compteur suivant.
  2. Les cartes ⚡ dorées sont sûres : retourne-les dans le jeu. S'il n'y en a pas, le 🎲 indique le pari le moins risqué (ou arrête-toi là).
  3. Après chaque carte retournée, touche-la ici et saisis sa valeur : l'analyse se met à jour instantanément.
  4. Le mode Pas à pas déroule le raisonnement règle par règle, comme un joueur expérimenté le ferait.
  5. Au clavier : chiffres pour saisir, Tab / → suivant, ← précédent, ⌫ effacer, Échap fermer. Sur une carte : 1 2 3 ou V. Pour une somme de 1 (rare), tape 1 puis Tab.
